# 阶段三实验导航

要判断是否提频，先读第 03、04 组；要看直接替换的 Verilog 和布线后仿真，读第 05 组。

| 实验 | 实现与验证 |
| --- | --- |
| [公共时钟与借时](01_公共时钟与借时/README.md) | 先验证在一条 BUFG 时钟网上部分替换 FF 后，Latch 能否借时。初始 25 个存储位中替换了 5 个，混合版的事务延迟从 5 拍变为 4 拍。20 ns 下出现借时，约 12.121 ns 下两版都受到输出接口限制。 |
| [关键路径选择与重定时](02_关键路径选择与重定时/README.md) | 固定功能和输出拍次，比较移动存储边界、添加补偿 FF、选择性换用 Latch 的影响。这里开始借鉴 Pairl 的候选选择方法。 |
| [公共MMCM与Howard提频](03_公共MMCM与Howard提频/README.md) | 在同一公共时钟架构下调整运算边界，并把 Howard 的预测周期送回 Vivado 核验。配对的纯 FF、混合实现分别在 9.213 ns、8.583 ns 通过。在这个对照中，混合实现保持输出拍次，且通过周期更短。 |
| [纯FF与混合方案的公平对照](04_纯FF与混合方案的公平对照/README.md) | 检验提频能否在更强的 FF 基准上保持。成对比较中一组从 115.236 提到 117.072 MHz，另一组从 121.464 降到 116.481 MHz。这批搜索记录中的最佳纯 FF 为 129.203 MHz，最佳混合候选为 127.992 MHz。 |
| [直接替换与门级时序仿真](05_直接替换与门级时序仿真/README.md) | 原 85 个 FF 中直接替换 16 个，得到 69 FF + 16 Latch；所有存储单元共用脉冲时钟。混合电路在 10 ns 下通过指定的慢角 SDF 数据核对，FF 对照使用 12 ns；这两个仿真点不能给出同条件最高频率差。 |
