# 公共MMCM对照实验（2026-11-13）

同一器件、引脚与IO约束，两组都增加一个MMCME2_BASE和反馈BUFG。倍频8、分频8，零相位、50%占空比；全部FF/Latch共用clk这一根BUFG网。工具会报告输入、反馈和生成时钟，但没有为数据存储设置多个独立时钟域。

原生布局布线与STA二分结果：

|方案|失败周期ns|通过周期ns|通过频率MHz|
|---|---:|---:|---:|
|ff_balanced|9.1982421875|9.19873046875|108.71065343171081|
|latch_short_4|10.60205078125|10.6025390625|94.31703048724326|

相比上一轮两组91.77MHz，混合方案约94.32MHz，纯FF约108.71MHz。公共输出时钟瓶颈缓解，但混合方案没有超过FF。

这是固定布线原生STA结果，检查setup、hold和脉宽。二分限定输入周期8–12ns，对应8倍VCO约667–1000MHz。保留原始综合/布局布线报告、通过/失败报告及DRC。尚未进行新增MMCM的锁定启动功能仿真、SDF仿真或上板验证。实际板级应等待LOCKED并同步释放数据通路复位；当前实验是稳定时钟条件下的STA，不是可交付上板方案。

原Howard导出器只支持FDCE/LDCE且假设直接主时钟，不能直接套用新增MMCM。此次未声称Howard已回验新时钟架构，也未宣称全局最高频率。
